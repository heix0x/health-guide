# 高中生身体健康指北

给高中生的一本身体使用说明。吃、睡、动、心情，还有你的胃。七章，约 1 万字。

**它是拿来查的，不是拿来从头读到尾的。**

---

## 打开

双击 `index.html`。没有构建步骤，没有依赖，不需要联网。

左侧目录点一章换一章；手机上点右上角「目录」。七个章节页 + 一页「写在前面」。

## 打印 / 存成 PDF

两件事分开做，别混：

**① 打全册**（24 页）
点侧栏「打印全册」。打印窗口里把「页眉和页脚」关掉，纸面会干净很多。

**② 只打某一章**
翻到那一章，点侧栏「只打印这一章」。打印窗口里出来的就只有这一章，不用在页码框里算范围。

**③ 要现成的 PDF 文件**

```bash
python tools/build_pdfs.py
```

`dist/pdf/` 下会生成 9 份：`全册.pdf` 加每一章各一份。

> ⚠️ 改了 `index.html` 的正文字句之后要重跑一次，否则 PDF 还是旧内容。
> 脚本自带检查：页数为 0、或者出现空白页，会直接报错退出。

## 目录结构

```
index.html              全书（单文件，样式与脚本全内联）
CHANGELOG.md            每一版改了什么、为什么改
docs/决策台账.md         当初为什么这么定（含被否掉的方案）
docs/内容依据台账.md      每句话凭什么这么说（A 素材 / B 官方文件 / C 通行定义 / E 刻意没写）
tools/build_pdfs.py     批量出 PDF
dist/pdf/               生成好的 PDF
```

## 两条写作纪律

- **读者知道的事实不进正文，读者不知道的判断才进正文。**
- **同一个句式，一页里只能用一次。**

## 隐私

`docs/资料库/` 存放采集到的一手素材，含真实姓名、QQ 号与聊天原文，**已列入 `.gitignore`，不进版本库**。正文里只用匿名化后的场景，不指向任何具体个人或学校。

本册为健康科普，不构成诊疗建议。持续不适请就医。
