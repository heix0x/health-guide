# 高中生身体健康指北

给高中生的一本身体使用说明。吃、睡、动、心情，还有你的胃。七章，约 1.1 万字。

**它是拿来查的，不是拿来从头读到尾的。**

---

## 打开

双击 `index.html`。没有构建步骤，没有依赖，不需要联网。

左侧目录点一章换一章；手机上点右上角「目录」。七个章节页 + 一页「写在前面」。

## 打印 / 存成 PDF

**① 打全册**（A4，23 页）

```bash
python tools/build_pdfs.py
```

直接印 `dist/pdf/全册.pdf`。页码（左下书名、右下页码）已经排进去了，A4 尺寸也定死了——别在打印窗口里勾「适应页面」，勾了会缩一圈。

在浏览器里点「打印全册」也能出，但那条路没有页码：Chrome 的浏览器页眉能带页码，代价是顶上一行 `file:///` 路径。

**② 只打某一章**
翻到那一章，点侧栏「只打印这一章」。出来的就只有这一章，不用在页码框里算范围。分章 PDF 的页码沿用全书页号，和封面索引对得上。

**③ 改了正文之后**

```bash
python tools/build_pdfs.py
```

脚本会先数一遍每章几页，把页码写回封面那张索引，再出 PDF。不重跑的话，`dist/pdf/` 是旧内容，封面索引的页码也是旧的。

> 脚本自带检查：页数为 0、出现空白页、或者某页只剩一两行字，都会报出来。

**④ 两个已知的坑**

- **存完的 PDF 别急着双击。** 浏览器写盘是异步的，文件名先落地、字节后写完，中间那几秒打开会报「无法打开此文件」。**等两三秒**就好。页面会在打印对话框关掉时提醒一句，但不会替你等——它拿不到写盘的进度。
- 打印目标选 Edge/Chrome 自带的**「另存为 PDF」**，不要选「Microsoft Print to PDF」：后者走 Windows 打印后台，那个"文件先出现、后写完"的窗口更长。
- **手机上打不了。** iOS Safari 会直接忽略打印调用，微信/QQ 内置浏览器是 WebView，连这个 API 都没有。点了没反应时页面会提示，但结论只有一个：**要用纸，换电脑**。

## 目录结构

```
index.html              全书（单文件，样式与脚本全内联）
CHANGELOG.md            每一版改了什么、为什么改
docs/决策台账.md         当初为什么这么定（含被否掉的方案）
docs/内容依据台账.md      每句话凭什么这么说（A 素材 / B 官方文件 / C 通行定义 / E 刻意没写）
tools/build_pdfs.py     批量出 PDF
dist/pdf/               生成好的 PDF
```

## 两条写作纪律

- **读者知道的事实不进正文，读者不知道的判断才进正文。**
- **同一个句式，一页里只能用一次。**

## 隐私

`docs/资料库/` 存放采集到的一手素材，含真实姓名、QQ 号与聊天原文，**已列入 `.gitignore`，不进版本库**。正文里只用匿名化后的场景，不指向任何具体个人或学校。

本册为健康科普，不构成诊疗建议。持续不适请就医。
