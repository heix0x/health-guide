# 《一根烟的事》是泛读者读物，不是学生读物

初版按高中生写：开场是课间厕所，第七章是德育处与校医室，第二章的主数据是「普通高中 72% 看到有人吸烟」。

但这本书的机制、数据和结论对任何抽烟或被动吸烟的人都成立。学生框架会把成年读者排除，也会让书看起来像校园宣传——读者一旦觉得「这是给学生看的」，就会把整本划到「跟我无关」那一类。

读者改为：抽烟的人，和每天闻得到烟的人。场景卡不再设校园：开场那间厕所不标学校，任何一栋楼都成立；其余换成家、写字楼、合租屋、小区门口、快餐店。第七章以室内公共场所、工作场所、餐馆、交通工具为主，「如果你还在上学」留一个小节。

**考虑过的方案**

- 只改封面话术：最省事，但正文里的「教学楼」「宿舍」「德育处」会继续把读者锁死。
- 拆成成人版和学生版：两版八成内容重复，维护成本翻倍。
- 一本泛读者版，学校作为场景之一：选这个。

**代价**

- 六处场景要重写，第二章的 72% 从主数据降为一句补充。
- 学生读者失去「专门写给我」的感觉，但第七章仍保留学校路径，正文也没有删掉青少年成瘾机制那一节。
