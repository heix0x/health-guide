# 正文不替这本书自己作证

两本书的开篇都有一节「这些话凭什么信」，四条承诺：数字有出处、不评判人（或「不卖东西」）、不够就说不够、有出口。位置在封面叙述之后、「用法」之前。

它不是事实错误，是位置和因果都错了。它要求读者先相信作者，再去看证据；而可信度是读出来的，不是声明出来的。它也不提供一个关于烟或身体的事实——遮住这一节，读者什么也不会少。

更实际的反作用在第五章：作者自己立了「不评判人」这条标准，读者后面每读到一句稍硬的判断，都会拿它来量。不声明的时候，读者只觉得「这书写得克制」；声明了，读者会检查。

**考虑过的方案**

- 删掉整节，什么都不补：选这个。四条里没有一条属于「不写会误导」。
- 只留「数字有出处」：正文每个数字本来就有来源标注，再说一遍是重复。
- 保留整节、把标题改软：换一种说法还是同一件事，只是更隐蔽。

**代价**

- 读者不会主动去注意脚注。但这件事靠声明解决不了，只能靠标注本身够清楚。
- 「不评判人」「不够就说不够」从承诺变成了要求：它们现在只能靠写法兑现，写偏了没有东西兜底。

**边界**

免责声明不算自证。「这是科普不是诊断，剂量看说明书」是防止误用，删了会有人照着做。判据：删掉之后读者会误用吗？会 → 留；只是少了一句保证 → 删。

**影响**
