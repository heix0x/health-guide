# 整仓 CC BY-NC-SA 4.0

两本书要公开，得先回答一个问题：别人能拿它们干什么。选整仓 CC BY-NC-SA 4.0，不拆「内容 CC + 脚本 MIT」，也不用 MIT。

**考虑过的方案**

- **整仓 MIT**：允许印成书卖、允许砍掉「这是科普不是诊断，持续不适应就医」那段再传播、允许改写成带货文案。它对内容被改坏这件事没有任何约束，只免作者的责。否决。
- **双许可（内容 CC + `tools/*.py` 用 MIT）**：软件圈常见做法，理由是脚本被别人拿去搭自己的书是好事。但这两个脚本写死了本书的章节锚点与目录结构，没有第二个使用者；维护两份许可文件是给不存在的人干活。否决。
- **整仓 CC BY-NC-SA 4.0**：选这个。署名、禁商用、改编后须同许可。去掉 ND 是有意的——一本健康读物最需要被人摘、被人贴进班级群、被改成自己学校的版本。

**代价**

- 脚本同受 NC 约束，别人想拿 `build_pdfs.py` 搭自己的书也受限。实际影响为零。
- GitHub 把许可证识别成 `NOASSERTION / Other`，仓库页少了那个小标签。试过三种排版都没变，不再折腾。

**踩坑依据**

- `LICENSE` 首行必须是官方标题 `Attribution-NonCommercial-ShareAlike 4.0 International`，且文件中不能夹中文段，否则 GitHub 识别失败。中文摘要因此另存 `LICENSE-中文说明.md`。
- Release 附件名用 ASCII：中文名经 API 上传会被截成 `-v2.2.pdf`。

**依据**：https://creativecommons.org/licenses/by-nc-sa/4.0/
