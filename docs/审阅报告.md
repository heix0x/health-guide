# 审阅报告 · v0.8 → v0.9

对象：`index.html`（11 208 字，正文七章 + 写在前面），打印稿 23 页。
问题：内容贴不贴近真实生活、能不能操作；作为要打印带进封闭寄宿学校的小册子，值不值得主动翻开。

---

## 0. 结论

| 问题 | 判断 | 分数（改前 → 改后） |
| --- | --- | --- |
| 贴近高中生真实生活 | **成立**。这是全册最强的一项，靠的不是形容词，是场景卡里的钟点、地点和动作 | 8.5 → 8.5 |
| 可操作性 | **只做到一半**。机制讲得清楚，但停在「说清楚」，缺「带多少、几点、做不到怎么办」 | 6 → 7.5 |
| 值得主动拿出来翻阅 | **改前不成立**。内容值得读，形态不值得带——纸面上没有页码、没有目录，最该查的两张表断在两页之间 | 4.5 → 8 |

一句话：**文字是这本书的资产，载体是它的负债。** 负债已经还掉大半，剩下的不是排版问题，是四个内容缺口。

还有一条必须先说：**打印稿一直在用手机版布局。** A4 纸宽 210mm ≈ 794px，`@media (max-width:900px)` 这个断点把它一起收进去了。于是纸上印出来的是「窄屏卡片」形态——三列表格被摊成一行行带小标签的堆叠块，行距和间距全是按手机调的。同一份内容（已含本轮新增段落），只修这一个断点，**26 页降到 23 页**：有 3 页纸是被一个媒体查询吃掉的。

## 1. 问题一：贴不贴近，能不能用

### 1.1 真实感是从哪来的（这是资产，一个字都别动）

- 场景卡全部落在具体时刻上：六点四十、食堂门口、宿舍楼下、第三节课下课接水、熄灯后摸黑换内衣。这是全书最难被替代的部分——换一个人写不出来，因为素材是访谈来的，不是想出来的。
- 细节是可以被读者认领的：九人间排队洗漱、离集合还有四分钟、药盒在枕头边上一直没打开、那袋核桃在柜子最里面一动没动。「带了没吃」比「带少了」扎人，因为它是真的。
- 反说教的克制是可信度的来源：「这本书里没有一件事是必须做的」「它不是『你得了什么病』」。同类读物九成在第三页就开始劝，这本没有。

**判断：这一层不要改。** 后面所有建议都不许碰场景卡和结语。

### 1.2 可操作性的分界线：说清机制 ≠ 给得出动作

全书的写法是「先讲机制，再给判断」，这套写法在解释上很强，在行动上会漏一步。漏的那一步通常是三种：

1. **量**——带什么说了，带多少没说。
2. **时点**——「睡前 3 小时别进食」说了，但晚自习结束到熄灯只有一个多小时，这条在执行层面是空的。
3. **退路**——每条建议都假设了理想条件（有十分钟、食堂还开着、能坐下来），没有一条写「做不到的时候，最差该怎么办」。

三处具体证据：

- **2.1 返校清单**：六行「带什么」，没有一行写数量。按清单自己的标准算一遍——每天 300ml 奶 × 21 天 = 6.3L，利乐包装要二十四五盒，**十二斤**。加上坚果、水果、燕麦，一个高中生返校那天背不动，九人间的柜子也塞不下。清单越正确，越不可执行。
  → 已补三段（见 §5）。结论是主力换成奶粉：同样的量，重量不到五分之一。
- **1.2 八格速查**：全册最好用的东西，但每格「现在能做」只有一句，多半是「慢点吃」「多喝水」「走十分钟」。正确，但空。
- **2.6 夜宵**：原文写「离熄灯至少两小时」，紧接着又说「第一章说睡前 3 小时不进食，这条在这儿一样成立」——同一段里两个数打架，而且两个都做不到。

### 1.3 一个结构性观察

七章里真正「可查」的只有两处：1.2 的八格、7.4 的药品表。其余五章是「可读」的。一本自称说明书的册子，可查内容占比不到两成。这不是缺点——可读的部分写得好——但它决定了这本册子的用法：**它不是工具书，是一本读完会记住几件事的小书。** 想让它在宿舍里被反复翻开，得往「可查」那头再挪一点。

## 2. 问题二：会不会被主动翻开

### 2.1 改前的判定：不会

不是内容的问题。是三个只要动手翻一次就会暴露的硬伤：

1. **纸面上没有页码，也没有目录。** 侧栏导航、章节跳转、`#ch1` 锚点——全部是网页能力，打印后归零。封面那句「翻到第七章」在纸上是一句空话，读者只能一页页捻。而这本书的自我定位是「可以查」。
2. **最该被查的两张表都被切断，且第二页没有表头。** 药品表在第 23 页印了前两行（对乙酰氨基酚、布洛芬），后四行翻到第 24 页，表头留在上一页。习惯账本同样断在第 5、6 页之间。用 div 拼的假表没有 `<thead>`，跨页时无从重复。
3. **纸是 Letter 不是 A4**（媒体框 612×792pt）。国内打印店和学校打印机全是 A4，结果是缩印 94% 或裁掉底边，四边留白不匀。

### 2.2 改后

- 页码由 `@page` 的边距盒生成，左下书名、右下页码，封面不印。
- 封面那张「入口」从四条网页锚点改成七行**纸面索引**，每行带页码（3 / 7 / 11 / 14 / 16 / 18 / 20）。页码不是手填的——构建脚本按实际分页回写，改一次正文重跑一次就自动对齐。
- 表格换成真 `<table>`：允许跨页，但 `<thead>` 会在下一页自动重印。既没有断头表，也没有为了不跨页而留下的半页空白。
- A4 落定，页边距 15/14mm。

### 2.3 还差什么才算「会被翻开」

一个判断：**这本书现在没有任何一页是「可以贴在柜门内侧」的。** 红旗九条在第 22 页，药品清单在第 21 页，八格速查在第 4 页——都在正文流里，翻到要三步。

如果还要再进一步，最值钱的动作不是加内容，是**把最后一页做成一张能单独撕下来/贴起来的东西**：九条红旗 + 七项常备药，一页装得下。这一条我没动，因为它会把 7.5 从第七章中间挪到书末，属于结构改动，等你拍板。

## 3. 逐章判断

每章四段：一句话判断 / 保留 / 调整 / 补充。

### 写在前面

**判断**：改前的第一页问对了问题（这跟我有什么关系、凭什么信、会不会又说教），但「用法」里有一条在纸上是自我拆台。

- **保留**：摘引「还行吧」那段 + 「这些话凭什么信」四条 + 免责说明。这四段是全书可信度的地基。尤其第三条「不够就说不够」——主动承认「吃什么能让人变聪明」查过但没写，比宣称权威有力。
- **调整**：用法第二条原文是「在家那两天：学校不带手机，你大概只有回家时才翻得到这个网页……打印一份带进去」。**读者手上拿的就是打印版**，这句话在跟他解释一个他不存在的问题。已改成「翻页靠页码」。同类错误全书只此一处，但它是 D-18（不复述读者已知处境）在新载体下的复发。
- **补充**：入口四条 → 七行索引（见 §2.2）。

### 第一章 · 你的胃，最先撑不住

**判断**：全书的样板章。三笔账 + 两笔隐账的结构，是可以拿去教写作的。

- **保留**：1.1 的三笔账（吃太快／时间乱／吃完就躺）；1.2 八格速查；1.3 账本；结语「胃很能忍」。
- **调整**（三处准确性问题，已改）：
  - 「蛋白质是**唯一**能让你撑到下一节下课的东西」——唯一不成立，脂肪和膳食纤维同样延缓胃排空。
  - 「吃饭时灌一大杯，会把胃酸**冲淡**，消化反而变慢」——机制站不住，胃酸会被缓冲回来。真实后果是胃被撑开、胀气更快。按本书自己「证据不足就不写」的标准，这句本来就不该出现。
  - 「胃疼就吃止痛药……**这类药**本身伤胃」——只有 NSAIDs（布洛芬等）伤胃，对乙酰氨基酚不伤。不点名，就和 7.4 的表打架。
- **补充**：建议加一条「连十分钟都没有」的退路（早读迟到、排队到最后）。现在 1.4 整节假设读者有十分钟——而那正是最缺的东西。

### 第二章 · 吃：一天三顿，能救回来

**判断**：立论最硬的一章。「食堂有没有」这个筛选标准，把一份购物清单变成了判断方法。

- **保留**：2.1 的筛选标准（食堂给不了／放得住三周／补最容易缺的）；2.5 喝水锚点法（挂在刷牙、下课、跑操后面，而不是设「八杯」目标）；2.7 一句话判据「半小时内还想再吃，它就不是食物，是味道」——全册最好的一句。
- **调整**：
  - 2.1 缺用量（见 §1.2）。已补三段，并把表里「钙」那行改成「常温纯牛奶（利乐包），或全脂奶粉」。
  - 2.6 的两个时间数打架。已改成「做不到就按顺序退：先减量，再减种类，最后才是时间」——把一条做不到的硬规矩，换成三条做得到的软次序。
- **补充**：含糖饮料。全书 0 次提及奶茶、可乐、功能饮料，而这是寄宿生最主要的额外糖来源，且直接接上第三章的睡眠问题（已在新 3.7 里补上咖啡因那一半）。

### 第三章 · 睡：熄灯之后

**判断**：机制写得最准的一章。「越努力越睡不着」和「放空不是清空，是替换」两节，是全书对读者最有解释力的一段。

- **保留**：3.1、3.2、3.5（眼罩／耳塞／被子三个物理变量——不到三十块，不要求改变任何习惯，全册最「能用」的一节）、3.7→3.8 回家作息。
- **调整**：3.4 的结论偏窄。「缺口补不回来」是对的，但能补的只剩「中午二十分钟 + 回家两天」，对一个每天睡六小时的人不够。真正能动的是**固定起床时间**和**早上见光**，这两条的证据比「早点睡」硬，也不要求他提前熄灯。
- **补充**（已加，新 3.7「下午那杯」）：咖啡因整段缺席。奶茶、可乐、功能饮料在高中生里极普遍，而「睡不够 → 早上靠它撑 → 晚上更睡不着 → 第二天更要靠它」是一个闭合的圈。半衰期约五小时，下午三点那杯到晚上十一点还剩三成。
- **补充**（建议）：睡眠问题没有红线。其余六章都有「什么时候该去看」，这一章没有——连续一个月入睡困难、白天撑不住，该说。

### 第四章 · 心：脑子停不下来

**判断**：写得最克制，也最薄。刻意压篇幅是对的（「有些话说多了成说教」），但压掉了一块不该压的。

- **保留**：4.1（「别紧张」是无效指令——身体先动，脑子后到）、4.2（盯过程不盯结果，配一个具体动作：圈题干关键词）、4.3 的 4-6 呼吸、4.5 四条界线（含「出现活着没意思这类念头，这条不用等」——写得明确又不吓人）。
- **调整**：4.4 只处理「想家」。寄宿生日常最大的情绪源不是想家，是**宿舍关系**：九人间，没有退出机制，躲不开。全书对人际冲突零覆盖。
- **补充**（建议，两条，都不长）：
  - 宿舍冲突的最小动作。不是讲沟通技巧，是讲「什么时候该换床位、该找班主任」——给界线，不给话术。
  - 熄灯之后情绪崩了怎么办。不能打电话、不能出宿舍、不能开灯，这八个小时怎么过。这是最具体、最没人写、最需要的一段。

### 第五章 · 动：你每天都在跑

**判断**：全书最漂亮的一次反转——用一笔账（1600 米/天）推翻了「你运动不够」这个前提，把问题重新定义为「连续坐多久」。

- **保留**：5.1 算账；5.2「总量」与「间隔」是两套机制；5.4 课间三分钟（站起来／看最远的东西／踮脚二十次）。
- **调整**：5.5 的「睡前二十个深蹲 + 三十秒平板」。对从不运动的人是受伤风险，对常运动的人没有意义。要么给零基础版，要么给进阶。
- **补充**（建议）：**跑伤了怎么办**。全书让读者每天跑一千六百米，却只字不提脚踝扭伤、膝盖前侧疼、足底疼。第七章把「扭伤」三个字塞进「值得跑一趟」里，等于没写。让你做一件事，却不给失败处理，是可操作性上的硬伤。

### 第六章 · 眼与身体：坐 14 小时之后

**判断**：最贴近日常的一章（九人间十五分钟那段几乎是纪录片），但有一处概念混淆，是全书最需要修的准确性问题。

- **保留**：6.4 九人间早晨十五分钟；6.5 经期（有机制、有界线、有药、有辟谣，完成度最高的一节）；6.3 眼保健操的替代（承认它有用的部分是「离开」，不神化也不否定）。
- **调整**（已改，最重要的一处）：
  - 原文把「20-20-20」当成护眼防近视的方案。**它缓解的是视疲劳（酸、干、胀），不改变度数。** 和度数涨不涨有关的，是户外时间和看近处的总时长。混在一起讲，读者会以为下课看远六十秒就在防近视。
  - 已把 6.2 拆成两件事，并补上户外光照（对还没近视的人证据最硬，对已近视的人挡不住涨但方向一致）和「每年验一次光」。
- **调整**：6.6「湿着睡不好，不是迷信——头皮受凉血管收缩，第二天容易头痛」。前半句对，后半句是民间说法套了个机制壳。已改成真实原因：头发潮着，枕巾和被窝跟着潮，人会在半夜反复醒。
- **补充**（建议）：眼镜度数与座位的关系（看不清别硬撑，眯眼歪头越凑越近才是让度数往上走的路）。已并入 6.2 末尾一句。

### 第七章 · 生病了，去哪儿

**判断**：全册写得最好的一章。7.1 把「听说药不管用」拆成三件事——事后解释、成本收益、样本天生偏斜——这是非虚构写作的水准，不是科普的水准。

- **保留**：7.1 整节，一个字别动；7.3 三句话（什么时候开始／什么感觉／有没有变重）；7.4 无剂量原则；7.5 九条红旗；7.6「硬扛一节课是意志问题，硬扛一天是判断问题」。
- **调整**：发烧阈值三处（第一章 38.5、7.2 38.5、7.5 39），读者串不起来。已在 7.5 开头加一句分层：「第一章那张管『该去医务室』，这张管『该往外转』」。
- **补充**：
  - 抗过敏药（已加氯雷他定一行）。7.2 把「过敏：起疹子、痒、局部肿」列为值得跑一趟，抽屉清单里却没有对应的东西——这是逻辑缺口。
  - 传染病在九人间的处置（建议）：诺如、流感在寄宿制学校是聚集性事件。现在只有半句「有传染性的（流感、诺如）」。缺的是「自己得了怎么不传给室友」和「室友吐了怎么办」。
