# 一根烟的事

吸烟、二手烟、三手烟，以及那句「关你什么事」。

写给抽烟的人，也写给每天闻得到烟的人。学校只是其中一个场景，不是这本书的边界。

七章，加一页「写在前面」和两页结语（含一页数字附录），约 1.2 万字，A4 二十三页。**它不是劝人戒烟的小册子，是把账算清楚的一本书。**

---

## 打开

双击 `index.html`。没有构建步骤，没有依赖，不需要联网。

左侧目录点一章换一章；手机上点右上角「目录」。七章 + 写在前面 + 结语。

## 打印 / 存成 PDF

```bash
python tools/build_pdfs.py
```

直接印 `dist/pdf/全册.pdf`。页码（左下书名、右下页码）已经排进去了，A4 尺寸也定死了——别在打印窗口里勾「适应页面」。

- **只打某一章**：翻到那一章，点侧栏「只打印这一章」。
- **改了正文之后**：重跑上面的命令。不重跑，`dist/pdf/` 和封面索引里的页码都是旧的。
- 脚本自带检查：空白页、只剩一两行的「薄页」，都会报出来。

浏览器里直接 Ctrl+P 也能出，但没有页码；要带页码的成品，用 `dist/pdf/` 里那份。存完等两三秒再双击——浏览器写盘是异步的。

## 目录结构

```
index.html              全书（单文件，样式与脚本全内联）
CHANGELOG.md            每一版改了什么
docs/决策台账.md         当初为什么这么定（含被否掉的方案）
docs/内容依据台账.md      每句话凭什么这么说
tools/build_pdfs.py     批量出 PDF
dist/pdf/               生成好的 PDF
```

## 在仓库里的位置

这是「健康指南」仓库里的子项目，和《高中生身体健康指北》（[`../student-health/`](../student-health/)）平级，不是任何一本书的附件。

两本书沿用同一套版式、交互与打印管线（`@page` 边距盒出页码、构建脚本回写封面索引），但正文、章节、文档与 PDF 各自独立，互不影响。

本册为健康科普，不构成诊疗建议或用药指导。戒烟药物为处方药，须在医生指导下使用。
