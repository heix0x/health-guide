## v0.10 · 2026-10-31

### 主题：两个"没反应"——存完打不开、手机点了不动

正文一个字没动，分页没变。这一版只补反馈。

#### A：存完的 PDF 打不开

现象：点打印、输入文件名、对话框关闭，桌面上立刻出现文件；这时双击，查看器报「无法打开此文件 / 出错了」。等几秒再开，一切正常。

原因不在页面：**Edge 存 PDF 是异步写盘**，文件名先落地、字节后写完，中间那几秒读到的是半个文件。写盘发生在浏览器进程里，页面拿不到任何进度——没有事件、没有字节数、没有完成回调。

| | |
| --- | --- |
| 改了什么 | 新增 `.toast` 浮层；`afterprint` 里弹一句「存好了？等两三秒再打开」；侧栏打印说明改写成两步 |
| 为什么 | 修不了写盘，只能修「你不知道要等」。**不做假进度条**——转三秒再消失是骗人的，下次照样打不开 |
| 影响 | 仅交互层；正文、分页、页码均不变（23 页） |

侧栏原文案「用 dist/pdf/全册.pdf 打印，页码已经排好；在浏览器里直接打印不会有页码」压成两句：一句指向成品，一句讲清浏览器这条路怎么走（目标选「另存为 PDF」，不要选「Microsoft Print to PDF」——后者走 Windows 打印后台，更容易出现"文件先出现、后写完"）。

#### B：手机上点打印没反应

iOS Safari 会静默忽略 `window.print()`，微信/QQ 内置浏览器是 WebView，连这个 API 都没有。**不猜机型**——同一台手机上 Chrome 可能能打、微信里不能，按 UA 一刀切会误伤。

判定依据只有一个：`beforeprint` 有没有触发。它跟打印对话框同步发生，弹了就一定触发。

- `doPrint()` 里置 `printStarted = false`，调用后 800ms 检查；没触发就弹提示，说明这台设备不支持，要用纸请换电脑。
- 手机抽屉里加一句静态说明，让人在点之前就知道。
- **不隐藏按钮**：Android Chrome 是能弹的，隐藏等于把能用的也一起废了。

- 打印 23 页（未变），各章无空白页、无薄页

## v0.9 · 2026-10-31

### 主题：把打印稿从手机布局里救出来，顺手补三个洞

触发是一次外部审阅（`docs/审阅报告.md`）：内容没问题，载体有问题。

#### A 类：打印稿一直在用手机版布局

A4 纸宽 210mm ≈ 794px。`@media (max-width:900px)` 这个手机断点，把打印也一起收进去了——纸面上印出来的是窄屏形态：三列表格摊成一行行带小标签的堆叠块，行距间距全是按手机调的。

同一份内容，断点改成 `@media screen and (max-width:900px)` 之后，**26 页 → 23 页**。

| | |
| --- | --- |
| 改了什么 | 两个断点加 `screen and` 限定 |
| 为什么 | 打印不是窄屏。一个媒体查询吃掉了三页纸，而且没人看得出来——因为堆叠之后的卡片本身是能读的 |
| 影响 | 全篇版式；三张表恢复三列；`.how`、`.sx-grid` 回到桌面形态 |

#### B 类：页码、目录、断头表

- `@page` 加 `size:A4`（原来是默认的 Letter，612×792pt，国内打印会被缩印或裁边）。
- 页码用 `@page` 的边距盒直接生成：左下书名、右下页码，封面不印。**不在 PDF 上盖章**——PDF 只是产物，源永远是 index.html。
- 封面「入口」四条 → 七行**纸面索引**，每行带页码。页码由构建脚本按实际分页回写，不手填；改一次正文重跑一次就自动对齐。
- 三张表（返校清单、习惯账本、常备药）从 grid 拼的假表换成真 `<table>`。假表没有 `<thead>`，跨页后第二页没有表头；换成真表之后，跨页时表头自动重印，也就不必再用 `break-inside:avoid` 把整块锁死、在页尾留半页空白。
- 删掉章末 `::after` 脚注。它在正文流里，一页装不下就独自掉到下一页，变成一张只剩一行的孤页（第六章就有一张）。换成跑马脚之后，页脚永远在白边里。

#### C 类：内容

- **2.1 补「带多少，先算重量」**。原清单有「带什么」没「带多少」。按它自己的标准算：每天 300ml × 21 天 = 6.3L，利乐包二十四五盒，**十二斤**——返校那天背不动，柜子也塞不下。改法：主力换成奶粉（同量重量不到五分之一），利乐包只带第一周。
- **新增 3.7「下午那杯」**，原 3.7 顺延为 3.8。咖啡因全书零提及，而「睡不够 → 早上靠它撑 → 晚上更睡不着」是闭合的圈。半衰期约五小时，下午三点那杯到晚上十一点还剩三成。
- **6.2 拆开「视疲劳」与「近视进展」**。原文把 20-20-20 当成防近视方案，实际它缓解的是酸干胀，不改变度数；和度数相关的是户外时间与看近处总时长。补户外光照与「每年验一次光」，标题改为「20-20-20，和它管不到的地方」。
- **7.4 加氯雷他定**。7.2 把过敏列为「值得跑一趟」，抽屉清单里却没有对应的药。
- **8 处准确性修正**：蛋白质「唯一」、饭中灌水「冲淡胃酸」、止痛药「这类药」、2.6 两个时间数打架、湿发睡「头皮受凉」、发烧阈值三处不衔接。逐条见 `docs/审阅报告.md` §4，已同步 `内容依据台账`。

#### D 类：写法

- 用法第二条「在家那两天」删掉，改为「翻页靠页码」。原文对拿着打印版的人解释「你大概只有回家才翻得到这个网页」——在解释一个他不存在的问题。这是 D-18 在新载体上的复发。

## v0.8 · 2026-10-31

### 主题：只打一章，别再算页码

正文一个字没动。这一版全是打印与工程。

#### 打印：一个按钮拆成两个

原来只有一个「打印 / 存为 PDF」，点下去弹窗里是整本 24 页。想只打第三章，就得在对话框里算「第三张到第五张」。**这是把排版知识推给读者**——他凭什么知道第三章在第几页。

| | |
| --- | --- |
| 改了什么 | 侧栏（和手机抽屉）改成「打印全册」+「只打印这一章」，后者下面一行小字跟着当前章节变，写的是「当前：第三章 睡：熄灯之后」 |

| 影响 | 仅 `#start` 侧栏与 `@media print`，正文一字未动 |

- 实现靠三个属性：`<html data-print-scope>` 表示「这次是单章」，`data-print-on` 标出留下来的那一章，`data-print-first` 放行它的 `break-before`——不然单章 PDF 的第一张是空白页。
- `.foot`（四行版权页）在单章打印时整个收掉，换成章末一行小字：`第三章 · 睡：熄灯之后　·　本册为健康科普，不构成诊疗建议`。三页纸配四行版权页太重，但免责一句不能丢。

- 新增 `?print=ch3`：进页面只设打印范围、不弹窗。给脚本用，也可以存成一个「直接打印第三章」的链接。

#### 新增 `tools/build_pdfs.py`

一条命令出 9 份 PDF（全册 + 每章一份）。调本机 Edge 的 headless 打印，逐个访问 `?print=<id>`。

**脚本带硬检查**：每份都用 pypdf 数页数、抽文字，页数为 0 或有空白页就报错退出。上一版那个「30 页全空白、页数却正常」的坑，这次变成了一道自动闸门——第一次跑它就抓到了第五章末尾的一张空白页。

#### 仓库

`git init`，两个 commit。`.gitignore` 排除 `docs/资料库/`（含真实姓名、QQ 号与聊天原文）和 `.workbuddy/`。

#### ⚠️ 一条维护负担

改了正文就得重跑 `python tools/build_pdfs.py`，否则 `dist/pdf/` 里是旧内容。README 和脚本开头都写了这句。

- **lede 改写**：「大部分人不去的理由只有一个：听说那儿的药不管用」→「**「药不管用」不是原因，是算完账之后，说给自己听的理由。**」
- **场景卡纠错**：原文写「上次去了，给的是板蓝根」，但素材明确记着本人**没去过**医务室，原话是「听他们说」。这是我们替她编了一段没经历过的经验——和 v0.5 修的是同一类错：拿想象的具体冒充真实的具体。
  - 改成一段对话：「你问她去过吗。她说没有，都这么说。」不需解释，二手信息自己就显形了。
- **7.1 重写**（「为什么大家不去」→「**不去，是一笔算过的账**」）：
  1. 说破：「药不管用」是决定做完后补的解释，不是决定前的判断
  2. 算账：成本确定（请假、排队、说清楚、落一节课、可能通知家里），收益不确定（去了也未必好）
  3. 确定的成本换不确定的收益——不去是账算得没错，与勇敢无关
  4. 传言为什么可信：说这话的人多半没去过；且信息天生偏斜——好了的人不会回来说，没好的人一定会说
  5. 哪一半是真的：药确实有限，但「第二天没好」不等于没用，药管的是难受不是好得快
  6. **漏算的一项：拖**——多数会自己好，有些不会，拖过某个点代价从「一节课」跳到「一周」
  7. 低估的一项：医务室值钱的地方是判断你要不要出去
  8. 换问法：不是「值不值得去」，是「这一次，是不是那种会自己好的」
- 7.2 收尾补一句扣回：「都属于『去了不亏』——而且都是『不会自己好』的那种。」
- 7.2–7.6 逐节审过，清单与话术不是复述，不动。

### 重写：2.1 返校清单

原清单自相矛盾——标题写「能放三周」，里面却有「鸡蛋，只放得住两三天」。根子是筛选标准错了：按"耐放"筛，会把食堂本来就有的东西（鸡蛋、豆干、面包）塞进自带清单，变成重复劳动。

- **新标准**：不是「能不能放三周」，是**「食堂有没有」**。三个条件——食堂给不了 / 放得住三周 / 补的是最容易缺的那几样。
- **表格列改了**：「带什么 / 用来干什么 / 注意」→「补什么 / 带什么 / 为什么食堂补不上」。列的改动本身就是立论。
- **删掉**：鸡蛋（食堂有，且放不住）、豆干（食堂有豆制品）、全麦面包（食堂有主食）。
- **新增**：常温牛奶（补钙）、原味混合坚果（好脂肪与镁）、苹果橘子梨（维 C 与纤维）、牛肉干卤蛋（补铁）、豆浆粉奶粉（错过饭点的蛋白）、即食燕麦（早饭那一口）。
- 同步调整了受影响的四处：场景卡（豆干→牛肉干）、2.4 早饭（面包→燕麦）、2.6 夜宵（面包鸡蛋→燕麦坚果）、2.7 对比句。

### 新增：2.1 末尾「关于『补脑』」

回答"有没有改善学习状态的食物"。查证后只写证据支持得住的部分：空腹上课、脱水、缺铁、血糖大起大落四件事，并明确「没有任何一种食物能让人变聪明」。
**刻意不写**：低 GI 饮食提高成绩（系统综述明确说无法下结论）、任何补脑保健品。
